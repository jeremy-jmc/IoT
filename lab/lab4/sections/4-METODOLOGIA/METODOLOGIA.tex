\section{Implementación del sistema de comunicación P2P con LoRa}

En esta experiencia se implementó un sistema de comunicación punto a punto (P2P) utilizando la tecnología LoRa y los módulos RAK3272S. El objetivo principal fue establecer una comunicación inalámbrica eficiente entre dos dispositivos, configurando uno como transmisor y el otro como receptor. Para ello, se emplearon comandos AT para ajustar los parámetros de enlace, como la frecuencia de operación, el modo de transmisión y otros aspectos relevantes para la comunicación P2P. Además, se integró la solución con Arduino y un sensor, permitiendo la transmisión de datos sensados a través del enlace LoRa. Esta experiencia permitió comprender el proceso de configuración, programación y validación de un sistema de comunicación inalámbrica de largo alcance, así como la importancia de la correcta conexión y parametrización de los dispositivos involucrados.

El Código~\ref{lst:codigo_sensor} muestra la implementación en Arduino para la transmisión de datos sensados a través del módulo LoRa RAK3172S. El programa lee el valor analógico del sensor conectado al pin A0, lo convierte a formato hexadecimal de cuatro dígitos y construye el comando AT correspondiente para enviarlo mediante la interfaz UART al módulo LoRa. Es importante destacar que se utilizan diferentes velocidades de comunicación (baudrates): 9600 baudios para la comunicación entre el Arduino y la PC, y 115200 baudios para la comunicación entre el Arduino y el módulo RAK3172S, asegurando así una transmisión eficiente y sin errores entre ambos dispositivos. Además, el código permite monitorear tanto el valor leído como la respuesta del módulo desde el monitor serial de la PC, facilitando la verificación del proceso de transmisión. El envío de datos se realiza de forma periódica, permitiendo así la comunicación continua entre el sensor y el receptor remoto.

\begin{lstlisting}[style=cppstyle, label={lst:codigo_sensor}, caption={Código de Arduino para enviar datos del sensor a través de LoRa}]
#define SENSOR_PIN A0       // Pin del sensor
#define RAK Serial1         // Puerto conectado al RAK (TX1/RX1)
#define BAUD_PC 9600        // Velocidad para PC
#define BAUD_RAK 115200     // Velocidad del RAK3172

void setup() {
  Serial.begin(BAUD_PC);    // Comunicacion con la PC
  RAK.begin(BAUD_RAK);      // Comunicacion con el RAK3172
  delay(1000);
  Serial.println("Inicio de transmision LoRa con datos del sensor...");
}

void loop() {
  int sensorValue = analogRead(SENSOR_PIN);  // Lectura (0 a 1023)
  Serial.print("Valor leido del sensor: ");
  Serial.println(sensorValue);

  // Convertir a hexadecimal y rellenar a 4 digitos con ceros
  String mensajeHex = String(sensorValue, HEX);
  while (mensajeHex.length() < 4) {
    mensajeHex = "0" + mensajeHex;
  }
  mensajeHex.toUpperCase();  // Opcional: para mantener todo en mayusculas

  // Enviar comando AT+PSEND=XXXX
  String comando = "AT+PSEND=" + mensajeHex + "\r\n";
  RAK.print(comando);

  Serial.print("Comando enviado al RAK: ");
  Serial.println(comando);

  // Leer respuesta del RAK
  unsigned long start = millis();
  while (millis() - start < 1000) {
    while (RAK.available()) {
      char c = RAK.read();
      Serial.write(c);
    }
  }

  delay(3000);  // Esperar antes de enviar de nuevo
}
\end{lstlisting}

\section{Sistema IoT de alerta de fuga de gas}

En esta sección se describe la implementación de un sistema IoT orientado a la detección y alerta temprana de fugas de gas en ambientes controlados, como laboratorios o instalaciones subterráneas. El objetivo principal de la experiencia es diseñar, construir y validar un sistema capaz de monitorear en tiempo real la presencia de gas y la temperatura, generando alertas visuales, sonoras y actuando sobre mecanismos físicos (como una esclusa de aire) en caso de detectar condiciones peligrosas. Además, se busca demostrar la transmisión inalámbrica de alertas mediante tecnología LoRa, permitiendo la comunicación entre el módulo detector y el módulo de alerta, incluso en entornos donde la conectividad WiFi es limitada.

El sistema está compuesto por dos módulos principales: el módulo detector y el módulo de alerta. El módulo detector integra sensores de gas (MQ-3) y temperatura (LM35), LEDs indicadores, buzzer, servomotor y el módulo LoRa RAK3172S, todo controlado por un Arduino MEGA. El módulo de alerta, por su parte, recibe los mensajes enviados por LoRa y los muestra en un terminal, permitiendo la supervisión remota del estado del sistema.

\begin{lstlisting}[style=cppstyle, label={lst:codigo_sensor}, caption={Código de Arduino para el sistema de alerta de fuga de gas}]
#include <Servo.h>

#define TEMP_PIN A0 // Sensor de temperatura (LM35)
#define GAS_PIN A1 // Sensor de gas (MQ-2 calibrado para LPG)
#define LED_ROJO 8 // LED para alta temperatura
#define LED_AZUL 9 // LED para fuga de gas
#define BUZZER 10 // Buzzer
#define SERVO_PIN 6 // Servomotor para esclusa
#define RAK Serial1 // Puerto Serial conectado al RAK3172
#define BAUD_RAK 115200

Servo esclusa;
int ultimoAngulo = 0;

void setup() {
  pinMode(LED_ROJO, OUTPUT);
  pinMode(LED_AZUL, OUTPUT);
  pinMode(BUZZER, OUTPUT);

  esclusa.attach(SERVO_PIN);
  esclusa.write(0); // Posicion inicial

  Serial.begin(9600); // Monitor serial
  RAK.begin(BAUD_RAK); // Comunicacion con RAK LoRa
  delay(1000);
  Serial.println("Sistema de monitoreo iniciado");
}

void loop() {
  float tempC = analogRead(TEMP_PIN) * (5.0 / 1023.0) * 100.0;
  int gasPPM = analogRead(GAS_PIN); // Lectura cruda MQ-2

  bool alertaTemp = tempC > 50.0;
  bool alertaGas = gasPPM > 80;

  if (alertaTemp) {
  alertaAltaTemperatura((int)tempC);
  }

  if (alertaGas) {
  alertaFugaGas(gasPPM);
  }

  // Si ya no hay fuga, asegurarse que la esclusa este cerrada
  if (!alertaGas && ultimoAngulo != 0) {
  esclusa.write(0);
  ultimoAngulo = 0;
  }

  delay(1000);
}

void alertaAltaTemperatura(int temp) {
  digitalWrite(LED_ROJO, HIGH);
  digitalWrite(BUZZER, HIGH);
  delay(500);
  digitalWrite(LED_ROJO, LOW);
  digitalWrite(BUZZER, LOW);
  delay(1000);

  String payload = "TEMP:" + String(temp);
  enviarPorLoRa(payload);
}

void alertaFugaGas(int ppm) {
  digitalWrite(LED_AZUL, HIGH);
  digitalWrite(BUZZER, HIGH);
  delay(1500);
  digitalWrite(LED_AZUL, LOW);
  digitalWrite(BUZZER, LOW);
  delay(1000);

  if (ultimoAngulo != 180) {
  esclusa.write(180); // Abrir esclusa
  ultimoAngulo = 180;
  }

  String payload = "GAS:" + String(ppm);
  enviarPorLoRa(payload);
}

void enviarPorLoRa(String mensaje) {
  String hexPayload = "";
  for (int i = 0; i < mensaje.length(); i++) {
  if ((byte)mensaje[i] < 16) hexPayload += "0";
    hexPayload += String((byte)mensaje[i], HEX);
  }
  hexPayload.toUpperCase();

  String comando = "AT+PSEND=" + hexPayload + "\r\n";
  RAK.print(comando);

  Serial.print("Mensaje enviado: ");
  Serial.println(mensaje);
}
\end{lstlisting}
